# Iris Flower Classification

## Overview
This project explores a basic supervised machine learning workflow by classifying Iris flower species based on sepal and petal measurements.

## Objectives
- Understand the basics of a dataset, features, and labels.
- Learn how to split data into training and testing sets.
- Build a classification model using K-Nearest Neighbors (KNN).
- Evaluate model performance using accuracy and a classification report.

## Tools

- Scikit-learn
- Google Colab

## Methodology

2. Split the dataset into training and testing sets.
